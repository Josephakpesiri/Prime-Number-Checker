# Prime-Number-Checker

🎯 YOUR TASK

Build a Python program that checks whether a number entered by the user is a prime number.

Your program should:

1️⃣ Ask the user to enter a number.

2️⃣ Use a for loop to check whether the number is divisible by any number other than 1 and itself.

3️⃣ Display whether the number is prime or not prime.

💡 EXPECTED RESULT

Example 1:

Enter a number: 7

7 is a prime number.

Example 2:

Enter a number: 10

10 is not a prime number.

⚠️ IMPORTANT

* You MUST use a for loop for the checking process.
* Remember that 1 is NOT a prime number.
* A prime number is greater than 1 and has exactly two factors: 1 and itself.
* Test your program with different numbers to make sure it works correctly.
